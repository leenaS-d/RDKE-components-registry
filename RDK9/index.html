Core RDK Entertainment Platform

RDK-E is an open, modular and scalable software platform for entertainment devices and streaming ecosystems. It provides a common software foundation for rapid innovation, simplified platform integration, secure content delivery and fleet-scale operations across diverse hardware platforms.

Why RDKE

Why RDK-E?

RDK-E standardizes core platform functionality while allowing operators, OEMs, and technology partners to focus on creating differentiated user experiences and services. The platform provides a layered architecture that improves portability, maintainability, and time-to-market.

Application Layer

Firebolt apps, the Lightning reference UI and the Firebolt framework — where portable third-party and OTT streaming apps run.

Middleware Layer

A single, consistent implementation of core device functionality — the Thunder framework, ENT services, media and DRM, and device management. This is where the Core RDK components live.

Vendor Layer

BSP, device drivers, HAL implementations, SoC adaptations and Linux OS integration — abstracting hardware differences behind the vendor layer.

Independent evolution

The layered architecture lets Application, Middleware and Platform components be developed, tested and updated independently.
